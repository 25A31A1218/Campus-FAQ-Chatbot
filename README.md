# 🎓 Campus FAQ Chatbot

An AI-inspired college FAQ chatbot that answers common questions about campus services and academic information.

## Features

- Admission FAQs
- Course information
- Exam information
- Library information
- Hostel information
- Attendance information
- Fee information
- Placement information
- Transport information
- Department information
- Simple and interactive Streamlit interface

## Technologies Used

- Python
- Streamlit
- Fuzzy matching
